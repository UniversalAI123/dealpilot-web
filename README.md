# Old address for CurbWhiz

This repo was the first home of the CurbWhiz (formerly DealPilot) web build. CurbWhiz is an iPhone app; the web app was retired on November 11, 2026. Every page here now forwards to https://universalai123.github.io/curbwhiz-web/. `sw.js` only removes the retired app's offline cache from browsers that still have it.
